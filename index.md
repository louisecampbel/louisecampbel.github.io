
# Bernie Backups

Bernie Backups is a private, self-hosted backup solution for personal use.

It uses Rclone to transfer encrypted backups from a Proxmox server to the owner's Google Drive account.

## Purpose

- Back up Home Assistant and Plex server configurations.
- Encrypt backup files before uploading them.
- Store backup copies securely in Google Drive.
- Automatically manage backup retention.

## Privacy and Security

This application is used solely by its owner.

It does not provide a public service, collect analytics, or sell personal data.

Google Drive access is used exclusively for managing the owner's backup files.
