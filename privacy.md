# Bernie Backups — Privacy Policy

## Overview

Bernie Backups is a private, self-hosted backup application used solely by its owner.

It uses Rclone and the Google Drive API to store encrypted backups of personal systems, including Home Assistant and Plex.

## Google Drive Access

The application requests Google Drive access to:

- Upload encrypted backup archives.
- List and verify stored backups.
- Delete old backups according to retention settings.
- Restore backups when required.

## Data Storage and Security

Backup files are encrypted locally before being uploaded to Google Drive.

OAuth credentials are stored on the owner's systems and are not intentionally shared with third parties.

## Data Sharing

Bernie Backups does not sell personal information, provide advertising, or collect analytics.

Data is transferred only as necessary to operate the owner's Google Drive backup service.

## Data Retention

Backup files are retained according to the owner's configured backup retention policy.

## Revoking Access

The owner can revoke Google Drive access at any time through Google Account security settings.

## Contact

This application is operated privately and is not available to external users.
